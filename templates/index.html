Neural Machine Translation for Low-Resource North-East Indian Dialects

Combines Unicode NFC normalization, Subword Byte-Pair Encoding (BPE), compact PyTorch Seq2Seq Transformer, and evaluation across BLEU, chrF++, and TER (Translation Edit Rate).

1. Data Processing & Features

Unicode normalization (NFC), punctuation detachment, morphological tokenization, and linguistic features (Type-Token Ratio, script character density).

2. Deep Learning Model

Custom Seq2Seq Multi-Head Self-Attention Transformer with Sinusoidal Positional Encoding & subword BPE to overcome Out-Of-Vocabulary (OOV) bottlenecks.

3. Rigorous Evaluation

Evaluated with BLEU (precision n-grams), chrF (character n-grams for agglutinative dialects), and TER (edit distance).
